# Netflix EDA [Learning Project] [Personal Repository]

This repository contains a personal learning project focused on Exploratory Data Analysis (EDA) using Python and Jupyter Notebook.

The project was created mainly for learning purposes by following tutorials, experimenting with code, and using AI-assisted guidance to better understand the EDA workflow and data analysis concepts.

## Objectives
- Practice data cleaning and preprocessing
- Explore movie and genre trends
- Visualize data using graphs and charts
- Understand basic EDA techniques using Python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Drama was the most frequent genre in the dataset
- Drama also received the highest audience popularity
- Spider-Man: No Way Home had the highest popularity score
- 2020 recorded the highest number of movie releases

## Note
This is a beginner-friendly learning project created to document my progress in data analysis and improve my understanding of EDA concepts.
